Carpeta para imágenes de las babosas de Bajo Terra.

- Coloca aquí un archivo SVG o PNG por babosa.
- El nombre recomendado es el nombre de la babosa en formato slug, por ejemplo:
  - infierno.svg
  - demoledora.svg
  - bubbaleone.svg
- Si no existe la imagen, la tarjeta mostrará un icono de respaldo.
